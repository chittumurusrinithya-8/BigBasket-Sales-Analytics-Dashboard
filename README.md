# 🛒 BigBasket Sales Analytics Dashboard

## Overview

This project presents an interactive Power BI dashboard developed to analyze BigBasket sales data and generate business insights. The dashboard helps monitor sales performance, profitability, customer behavior, and product category trends.

---

## Objectives

- Analyze total sales and profit
- Track order performance
- Compare category-wise sales
- Identify top-performing products
- Monitor regional performance
- Support business decision-making

---

## Dashboard Features

- KPI Cards
- Sales Trend Analysis
- Profit Analysis
- Category-wise Performance
- Customer Analysis
- Payment Mode Analysis
- Dynamic Filters
- Drill-through Reports

---

## Tools & Technologies

- Power BI
- Power Query
- DAX
- Microsoft Excel

---

## KPIs

- Total Sales
- Total Profit
- Total Orders
- Average Order Value
- Year-over-Year Growth
